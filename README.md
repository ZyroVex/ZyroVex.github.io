# ZyroVex

ZyroVex is a handmade game project featuring a custom-built 3D module. It was created in just a few days and is designed to support both online and offline play.

## Offline Play

You can install and play ZyroVex offline. However, progress will not be saved when the game is played offline, including leaderboard progress.
